Studio

Studio regroupe les outils internes qui servent à préparer, envoyer et suivre les vidéos de nos propres chaînes (YouTube, Instagram, Facebook, TikTok).

Ces outils ne sont pas proposés au public : ils ne fonctionnent qu'avec nos propres comptes. Ils utilisent les API officielles des plateformes.

  • YouTube Data API et YouTube Analytics API : envoi de nos vidéos en privé, mise à jour de leurs descriptions, lecture de leurs statistiques.
  • API Graph de Meta : lecture des statistiques de nos Reels Instagram et Facebook.

Comment nous traitons les données : règles de confidentialité.
